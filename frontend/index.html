Ensemble Architecture — 5 Detection Methods

Each method contributes a weighted vote. Combined score = weighted average of all methods.

Siamese LSTM 35%

Deep semantic similarity using shared-weight LSTM encoders. Learns sentence meaning at a neural level.

Accuracy62.3%

TF-IDF Cosine 20%

Vocabulary-based similarity using Term Frequency–Inverse Document Frequency with cosine similarity scoring.

Accuracy~71%

N-gram Jaccard 15%

Bigram and trigram Jaccard similarity. Captures phrase-level overlap and paraphrasing patterns.

Accuracy~65%

Char N-gram (4-gram) 15%

Character-level n-gram matching. Detects character-stripped plagiarism and word-substitution attacks.

Accuracy~62%

LCS Ratio 15%

Longest Common Subsequence ratio. Structural similarity measure that tracks sentence flow and ordering.

Accuracy~58%

Processing Pipeline

1

Input Reception

User submits text directly or uploads PDF/DOCX/TXT file. Flask receives via REST API or multipart/form-data. Text is validated for length (min 15 chars, max 50,000 chars).

2

Text Extraction & Preprocessing

PyPDF2 extracts text from PDFs, python-docx from DOCX files. Text is lowercased, punctuation normalized, numbers/extra whitespace removed. Sentence splitting via regex.

3

Ensemble Similarity Analysis

5 independent methods compute similarity scores in parallel: (1) Siamese LSTM encodes both texts to semantic vectors, (2) TF-IDF vectorizer computes cosine similarity, (3) N-gram Jaccard measures bigram/trigram overlap, (4) Character 4-gram Jaccard catches stripped plagiarism, (5) LCS ratio measures structural similarity. Final score = weighted average (35% LSTM, 20% TF-IDF, 15% N-gram, 15% Char, 15% LCS).

4

Per-Sentence Analysis

Each sentence is individually scored against a 206-text baseline corpus of academic reference material. Sentences exceeding the threshold get flagged with similarity level (safe/low/medium/high/critical), color coding, and the matched reference text.

5

Score Classification & Report Generation

Final ensemble score determines risk level: Safe (0–0.2), Low (0.2–0.4), Medium (0.4–0.6), High (0.6–0.8), Critical (0.8–1.0). Report includes: SVG gauge visualization, risk meter, level badge, AI explanation, sentence-level analysis, method breakdown, word/char/sentence counts.

6

Storage & User History

Authenticated results are stored in SQLite with user association, timestamp, score, and level. Dashboard allows viewing full history, re-checking reports, and exporting results as text files.

Siamese LSTM Neural Network Architecture

         ↓
Embedding  (20K vocab → 128 dim)
         ↓
LSTM Encoder  (64 units, shared weights)  ←── shared ──→  LSTM Encoder (64 units)
         ↓                                                      ↓
Vector A  (64-dim)                                    Vector B  (64-dim)
         ↓                                                      ↓
         Subtract → Multiply → Add (element-wise fusion)
         ↓
Dense(128, relu) → Dropout(0.4) → Dense(64, relu) → Dropout(0.4)
         ↓
Dense(1, sigmoid) → Plagiarism Score (0.0 – 1.0)

Neural Network Layer

  • ✓ Shared-weight LSTM twin encoders
  • ✓ 128-dim word embeddings (20K vocab)
  • ✓ Element-wise Subtract + Multiply + Add fusion
  • ✓ Two Dense layers (128 → 64) with ReLU
  • ✓ Dropout 0.4 for regularization
  • ✓ Sigmoid output (plagiarism probability)

Ensemble Layer

  • ✓ LSTM: 35% weight — semantic understanding
  • ✓ TF-IDF: 20% weight — vocabulary overlap
  • ✓ N-gram: 15% weight — phrase matching
  • ✓ Char 4-gram: 15% weight — char-stripping
  • ✓ LCS: 15% weight — structural similarity
  • ✓ Weighted average → final score

Data Layer

  • ✓ SNLI corpus: 367,373 labeled pairs
  • ✓ Positive: source ↔ plagiarism_txt
  • ✓ Negative: source ↔ random sentence
  • ✓ 206 academic reference texts
  • ✓ Baseline corpus for sentence scoring
  • ✓ SQLite: users + checks tables

About the Project

VeriCheck is a plagiarism detection system developed as a Capstone Project at the Indian Institute of Technology Patna (IIT Patna). The system uses a Siamese LSTM neural network to detect semantic similarity between text documents.

Our model is trained on a combination of the SNLI (Stanford Natural Language Inference) dataset and custom plagiarism datasets, achieving 86% accuracy in detecting plagiarized content.
